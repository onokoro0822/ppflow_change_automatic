## 結論

- 店舗所在地と出力gcodeの不一致を`--facility-city-match on`で解消した（以後の正しい仕様として採用）。
  ただし旧係数のままonにすると施設到着371→228件、施設出発地TVD 0.396→0.423と悪化した。
- 中京PT 2022の到着施設別ODから、大型規模小売店（買物の22.4%）とそれ以外で行先都市MNLを別々に推定し、
  買物の22.4%を大型店分岐として扱う任意オプションをJavaに追加した。新施設には大型店分岐の買物だけが来る設定にした。
- 2%・seed42で施設出発地TVDは0.396（旧採用）→0.349（採用案）、愛知県内参照は0.388→0.318。施設到着360件（目標360件）。
  seed42〜45の平均ではTVD 0.431→0.354、施設到着は平均362件（標準偏差23.7）。
  **TVDは校正目標そのもの（標本内）であり、外部検証ではない。**採用案の距離倍率0.45はPT推定値0.777より弱く、
  愛知全体の買物の同一地区率は0.697（旧）→0.621（PT 0.707）へ離れる。この副作用込みの妥協案である。
- 全数（sample-factor 1、seed42）のbaseline・計画を実行し、施設到着17,965トリップ/日（目標18,000、−0.2%）、施設出発地TVD 0.348（愛知県内0.318）。
  ただし来訪者の97.2%はbaselineで同じ駅メッシュの既存店に行っていた人で、中村区全体の買物は+0.4%（+239）にとどまる。

## 1. 店舗所在地と都市の一致（`--facility-city-match`）

境界メッシュは接する全市区町村に登録され、別の区の店舗も含む。onでは選んだ都市の店舗だけから選び（なければ全店舗）、
出力gcodeを店舗自身の行政コードにする。offは従来どおり。

| seed42・2% | off（旧） | on（旧係数） |
| --- | ---: | ---: |
| 施設到着（目標360） | 371 | 228 |
| 施設出発地TVD | 0.396 | 0.423 |
| 中村区内の割合（PT 0.341） | 0.326 | 0.553 |
| 西区の割合（PT 0.031） | 0.197 | 0.048 |

offの西区・北区の過大は、隣接区の選択者が共有メッシュの中村区店舗に到着していたことによる。
onで解消したが、中村区を選んだ人だけが施設に来るため区内割合が過大になった。

## 2. 大型店と一般の買物を分けたMNL推定

`pflow_large_store_estimation.py`。入力は本人書き出しの全OD（中ゾーン×到着施設×目的細分類×年齢、
`中京PTデータ/chukyo_pt_2022_od_facility_purpose_age.csv`、md5 `fede8edb2b5a20e7480250a78a4e1270`）。
買物（日常的な家事・買物＋日常的でない買物）の22.389%が大型規模小売店への到着。年齢別は19〜31%（10代が最大）。
愛知県内の同一比較単位率は大型0.591、それ以外0.741。

係数は研究室MNLへの倍率 x=[β, 距離, 面積, 人口比, オフィス比, 同一都市]。出発単位をseed13でtrain/validation/testに分割
（`pflow_accessibility_estimation`と同じ）。代理モデルはPTの物理地区を、Javaのon出力（店舗所在都市）と同じ単位で比較する。

| モデル（trainで推定） | 大型店test平均対数確率 | 一般test | 中村区着大型店の出発地TVD |
| --- | ---: | ---: | ---: |
| 現行単一モデル | −1.5786 | −1.2485 | 0.378 |
| 全買物で再推定 | −1.5668 | −1.2484 | 0.374 |
| 一般のみで推定 | −1.5977 | −1.2298 | 0.394 |
| 大型店のみで推定 | −1.5407 | −1.3455 | 0.324 |

- 同一都市の倍率はどのモデルも0になった。研究室の同一都市係数は勤労者・学生で0、非勤労者で小さな負値で、ほぼ効かない。
- 探索半径を20kmから広げる案は不採用。中ゾーン5着の大型店買物で20km外は5.1%だけで、20km内の同じトリップでの対数確率は30kmで−1.5605と悪化した。
- 大型店の魅力を`log(1+Σ E_m^p / max(d,1km)^q)`（E: メッシュの卸売小売従業者）とする候補15通りをvalidationで選び、p=2,q=0を採用（validation −1.4905）。
  testは−1.5793で、p=1（−1.5407）よりむしろ悪い。対数尤度での明確な優位はない。pを大きくすると駅前のような集積メッシュが強く効き、
  代理モデルで大型店の中村区着の割合が4.2%→5.1%（PT 6.3%）に近づく。
- 全出発単位で再推定した係数（Javaへ渡す値）: 一般 β=0.2421875、倍率0.953125,0.03125,−2.84375,−0.8046875,0。
  大型店（p=2,q=0）β=0.3984375、倍率0.77734375,−0.15625,−12.3515625,−0.03125,0。

## 3. Javaの任意オプション（Pseudo-PFLOW-v3、ブランチfeature/capacity-scenario）

- `--facility-city-match off|on`（commit `f9f31cf`）
- `--shopping-large-store share,β,距離,面積,人口比,オフィス比,同一都市`: 買物の行先選択で、確率shareで大型店分岐の係数を使う。share 0（既定）では乱数を引かない。
- `--shopping-large-store-accessibility p,q`: 大型店分岐だけの魅力項。未指定なら一般と同じ項。
- `--large-store-facility-only on`: シナリオ施設（id>0）には大型店分岐の買物だけが来る。
- `--shopping-mnl-multipliers`に任意の5番目（同一都市倍率、既定1）。
- commit `e5ce559`。既定設定でseed42 baselineを再生成し、旧baselineと207 CSVが`diff -rq`で完全一致（実装の途中・最終の両方で確認）。
- Pythonテスト: `tests/test_pflow_large_store_estimation.py`（PT表の分割、スコア、TVD）を追加し、全113件成功。

## 4. 2%・seed42でのシミュレーション校正

PT参照は中ゾーン5の大型規模小売店着・買物20,796トリップ（中村区内34.1%、市内他区41.0%、愛知県他18.7%、県外6.3%）。
`pflow_origin_comparison.py`のcalibrated_facility。f=1e9は施設capacity 10億（メッシュ内のほぼ全大型店分岐が施設へ）。

| 設定 | 施設到着 | TVD | TVD（愛知） | 中村区内 |
| --- | ---: | ---: | ---: | ---: |
| 旧採用・off・f8e6 | 371 | 0.396 | 0.388 | 0.326 |
| 旧係数・on・f8e6 | 228 | 0.423 | 0.392 | 0.553 |
| 大型店分岐p=1・f1e9 | 331 | 0.425 | 0.395 | 0.535 |
| p=2・距離0.777・f1e9 | 363 | 0.407 | 0.376 | 0.515 |
| p=2・距離0.777・f4e8 | 361 | 0.406 | 0.375 | 0.515 |
| p=2・同一都市−1・f1e9 | 361 | 0.411 | 0.381 | 0.518 |
| p=1.5,q=2（train係数）・f1e9 | 346 | 0.388 | 0.357 | 0.517 |
| p=2・距離0.6・f1e9 | 362 | 0.376 | 0.345 | 0.489 |
| **p=2・距離0.45・f1e9（採用）** | **360** | **0.349** | **0.318** | **0.461** |
| p=2・距離0.3・f1e9 | 364 | 0.319 | 0.286 | 0.431 |
| p=2・距離0.15・f1e9 | 364 | 0.298 | 0.263 | 0.409 |

- PT推定の係数のままではシミュレーションの区内割合が代理モデル（0.42）より高い0.52になる。
  区内の行先メッシュ選択（同一都市は前の活動地からの距離重み）と、勤務・自由活動の後の連鎖トリップが加わるため。
- 同一都市倍率は効かず、大型店分岐の距離倍率だけが区内割合と遠方の不足（PTにあるが0件の単位）を改善した。
- 距離を弱めた代償（baseline・愛知全体の買物、PT全買物と比較）:

| baseline | 同一比較単位率（PT 0.707） | 行先TVD | 平均直線距離 |
| --- | ---: | ---: | ---: |
| 旧採用・off | 0.697 | 0.095 | 4.07km |
| 旧係数・on | 0.661 | 0.094 | 4.00km |
| p=2・距離0.777 | 0.671 | 0.095 | 3.95km |
| p=2・距離0.45 | 0.621 | 0.094 | 4.47km |
| p=2・距離0.3 | 0.596 | 0.089 | 4.82km |

代理モデルでも距離0.45は大型店ODの全体対数確率を−1.552→−1.742へ下げる（`large_distance_sensitivity`）。
距離0.45は施設TVDの改善（−0.047）と同一地区率の乖離（0.010→0.086）の妥協として選んだ判断であり、最適性の検証ではない。
0.3以下はさらに施設TVDが下がるが、愛知全体の局所性の乖離が大きいため採用しなかった。本人の判断で変えてよい。

- 施設capacity: p=2の各案で、f=1e9でも到着は360〜364件で、目標360件にほぼ等しい上限だった。
  つまり18,000トリップ/日の目標は、駅メッシュへ来る大型店分岐の買物をほぼ全て新施設が取る場合にだけ届く。
  中ゾーン5の大型店着は現状PTで20,796トリップ/日で、目標はその87%に当たる。目標値か大型店割合のどちらかに無理がある可能性を残す。

## 5. 全数実行（sample-factor 1、seed42）

採用設定・`plan_dept2014_f1000000000.json`（従業者加算745.943、施設capacity 1e9）と同設定のbaseline。
PFLOW_HOME=`/Volumes/PFLOW_SSD/PFLOW`、`MAVEN_OPTS=-Xmx6g`で2ケースを同時実行し、各30.5分（Commuter生成617秒、NonCommuter498秒）。
各207 CSV・`.complete`あり・各1.5GB、例外・`[ERROR]`・コンパイル異常なし。学生生成失敗はbaseline 3,224件・計画3,228件（2%は両ケース65件）。
出力: `/Volumes/PFLOW_SSD/PFLOW/output/fullsample_20261014/{baseline,plan_dept2014_f1000000000}/`。

| 指標 | 2%（×50換算） | 全数 |
| --- | ---: | ---: |
| 施設の買物到着（目標18,000） | 360（18,000） | **17,965**（−0.2%） |
| 施設出発地TVD／愛知県内参照 | 0.349／0.318 | 0.348／0.318 |
| 施設の出発地 中村区内／市内他区／愛知県他（PT 0.341／0.410／0.187） | 0.461／0.361／0.178 | 0.447／0.410／0.142 |
| PTにあり生成0件の単位のPT割合 | 0.145 | 0.048 |
| 中村区の店舗所在地への買物到着 baseline→計画 | 1,224→1,232 | 61,333→61,572（+239、+0.4%） |
| 区外自宅から直接の中村区店舗到着 | 403→409 | 19,264→19,393（純増の下限〜上限 +102〜+148） |

- 全数の買物総数は2,001,565（baseline）。所在地不明13,273件。選択都市と所在地の中村区到着は61,442と61,333で、onでも0.2%の差が残る（都市内に一致店舗がないメッシュでは全店舗から選ぶため）。
- 施設到着17,965件のbaselineでの同じ活動は、同じ駅メッシュ52366700の店舗17,455件（97.2%）、中村区の他メッシュ381件、中村区外129件。
  **施設の来訪者のほとんどは、同じメッシュの既存店からの転換である。**中村区全体の買物は+0.4%しか増えない。
  f=1e9で施設がメッシュ内の大型店分岐をほぼ全て取る設定と、目標18,000がその上限に近いことの帰結。
- 全数ではPTにあり0件の単位が0.145→0.048と減り、標本数の少なさによる欠落は減った。一方、中村区内0.45はPT 0.34より高いまま。
- 1seedの結果であり、全数の乱数ばらつきは未確認。施設条件付きの外部検証は未完了。
