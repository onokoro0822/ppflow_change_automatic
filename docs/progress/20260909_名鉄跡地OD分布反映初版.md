# 名鉄跡地への出発地分布反映とOD変更 初版

作成日: 2026-09-09 JST

## 結論

名鉄跡地でも中京PTの用途別出発地分布を利用できる。ただし、名鉄跡地単体の観測商圏ではなく、
跡地を含む到着中ゾーン5への商業用途代理分布を、跡地の仮想施設へ移植する感度分析である。

## 初版シナリオ

- 対象: 旧・名鉄百貨店本店跡地の全商業型
- 需要量: 25,284到着トリップ/日
- 需要量の根拠: 旧本店売場面積相当54,374㎡を全商業用途とした比較用推計
- Pseudo-PFLOW候補: 品質基準適合かつ買物目的100
- 対象点: 136.88397984, 35.16967402
- 公式ゾーン判定: 中ゾーン5、基本ゾーン510
- 抽出単位: 1人につき1到着トリップ

## 処理方法

1. origin_distribution_by_facility_use.jsonの商業用途94ゾーン構成比へ25,284件を最大剰余法で配分する。
2. 公式コード表Sheet2の第6回基本ゾーンWKTで、候補の出発座標を中ゾーンへ変換する。
3. Excelセル上限により途中切れしたWKTは推測せず、該当点を分類不能として除外する。
4. 同一人物の候補が複数ある場合は、固定seedのSHA-256順位で1件だけ残す。
5. 中ゾーン別の割当数まで候補を再現可能に選ぶ。候補不足ゾーンの残数は、候補がある目標ゾーン内で再配分する。
6. 選択トリップの目的地を名鉄跡地代表点へ置換し、同一分析系列の次トリップがあれば、その出発地も同じ点へ置換する。
7. 元SQLiteは読み取り専用とし、変更後OD行と座標差分を別CSVへ出力する。

## 実データ結果

- 品質基準適合・買物目的候補: 271,086トリップ
- 公式境界で分類できた候補: 251,347トリップ
- 分類不能: 17,753トリップ
- 既に跡地50m以内へ到着するため除外: 1,986トリップ
- ゾーン分類後の一意候補人物: 163,935人
- 選択: 25,284人・25,284到着トリップ
- 変更対象OD行: 44,909行
- 到着目的地変更: 25,284件
- 後続トリップ出発地変更: 19,625件
- 同一人物重複: 0件
- 連続する選択到着: 0件
- 変更後最大チェーン接続誤差: 0.0m
- 時刻変更・交通手段変更: 0件
- 元SQLite変更: なし

目標94ゾーンのうち、候補を選択できたのは52ゾーンである。全変動距離（TVD）は0.09263、
構成比ポイント表示では9.26ポイントだった。主因は、公式Excelの499 WKTのうち255セルが
32,767文字で途中切れしていることと、名古屋市版Pseudo-PFLOW候補に遠方ゾーンが存在しないことである。
初版は誤ったゾーン推定を避けるため、欠損境界を近傍補間していない。

## 限界と次工程

- 完全な基本ゾーンGISを入手して分類不能を減らし、TVDを再評価する。
- 名古屋市外の居住者を表現するには、愛知県・中京都市圏全体のPseudo-PFLOW入力が必要である。
- 現行分布は到着施設列を持たない目的代理であり、施設別同時クロス表が得られれば置き換える。
- 年齢×性別人物マスタを結合し、時間帯、交通手段、前後目的、営業時間を順に条件へ追加する。
- 初版は既存買物活動の置換であり、新規誘発活動の挿入は別モデルとして扱う。
