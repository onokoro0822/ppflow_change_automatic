# 中京PT用途別出発地分布 初版

作成日: 2026-09-09 JST

## 目的

年齢×性別分布に続くPseudo-PFLOW変更モデルの入力として、名鉄名古屋周辺へ来るトリップが
どの中ゾーンから出発するかを商業・オフィス・ホテル別に作る。

## 入力と対象範囲

- 入力: `中京PTデータ/chukyo_pt_2022_od_purpose_mode_raw.csv`
- ゾーン対応: `中京PTデータ/中ゾーンコード表/pt_system_code_table.xlsx`
- 対象到着地: 中ゾーン5（愛知県名古屋市中村区。名鉄名古屋周辺を含む広域ゾーン）
- 単位: 第6回中京都市圏PT調査の拡大後トリップ数
- 出発地: 居住地ではなく、当該トリップの直前活動地点である中ゾーン

## 集計式

現在のOD表には到着施設がないため、施設用途`f`ごとに対応する目的集合`P_f`を定め、
出発中ゾーン`o`、到着中ゾーン5、目的`p`の拡大トリップ数`T(o, 5, p)`から次を計算する。

```text
N_f(o | D=5) = Σ[p ∈ P_f] T(o, 5, p)
P_f(o | D=5) = N_f(o | D=5) / Σ[o] N_f(o | D=5)
```

交通手段別セルも同時に合計し、JSONの各出発ゾーンへ`mode_counts`として保存する。
将来、入力CSVに`到着施設`列が含まれる場合は、施設名と目的集合の両条件を使う。

## 用途条件

| 用途 | 参照する到着施設 | 目的集合 |
| --- | --- | --- |
| 商業 | 大型規模小売店 | 日常的な家事・買物、日常的でない買物、食事・社交・喫茶、娯楽・文化活動、観光・行楽・レジャー、その他の自由目的 |
| オフィス | 事務所・会社・銀行・郵便局 | 出勤、打合せ・会議・仕事、書類持参・受領・集金、販売・配達・仕入れ・購入、作業・修理、その他の業務目的、帰社・帰校 |
| ホテル | 宿泊施設・ホテル | 観光・行楽・レジャー、打合せ・会議・仕事、食事・社交・喫茶、その他の自由目的、その他の業務目的 |

## 実データ結果

| 用途 | 対象トリップ数 | 出発中ゾーン数 | 上位5ゾーン（構成比） |
| --- | ---: | ---: | --- |
| 商業 | 87,446 | 94 | 5 中村区 43.57%、6 中区 9.02%、10 中川区 5.88%、4 西区 4.63%、8 瑞穂区 3.59% |
| オフィス | 156,774 | 122 | 5 中村区 17.87%、6 中区 6.86%、10 中川区 6.49%、4 西区 4.64%、1 千種区・東区 3.71% |
| ホテル | 53,913 | 83 | 5 中村区 36.67%、6 中区 10.82%、10 中川区 5.73%、4 西区 4.73%、11 港区 3.41% |

入力41,970行のうち到着中ゾーン5は819行で、交通手段別合計と行合計の不一致は0行だった。
各用途の出発地構成比合計は浮動小数点誤差の範囲で1.0になった。

## 限界と次の接続作業

1. 現在のOD表には`到着施設`がないため、結果は施設の厳密な分布ではなく目的ベースの代理分布である。
2. 用途間で目的が重複するため、商業・オフィス・ホテルのトリップ数は相互排他的ではなく合算できない。
3. 中ゾーン5は名鉄跡地だけではなく中村区の広い範囲を含む。名鉄跡地固有の観測分布ではない。
4. ODのOは直前活動地点であり、居住地分布を得るには世帯・個人の居住地項目を別途集計する必要がある。
5. Pseudo-PFLOWの緯度経度を中ゾーンへ対応付けるには、中ゾーン境界GISまたは同等の座標対応が必要である。
6. 厳密化には`出発中ゾーン×到着中ゾーン×到着施設×目的`の同時クロス表または利用可能な明細が必要である。

次は、Pseudo-PFLOW候補トリップの出発座標を中ゾーンへ変換し、このJSONの
`P(origin_zone | facility_use, D=5)`へ合うように商業目的トリップを再現可能に抽出する。
