## 現行方針と旧実験の区別

- 2026年8月7日MTG以降の中心は、名鉄跡地の計画A・B・Cについて、施設用途・規模から来訪者数と属性構成を根拠付きで設定し、シナリオ別人流を生成・比較する分析である。
- 旧・名鉄百貨店本店の営業終了後に買い物トリップを再配分した分析は、チェーン変更技術を確認した2026年8月6日の初期実験として保存する。
- ミッドランドスクエアを参照施設としたFCPI型分析と、200人を旧本店付近へ誘引した新施設モデルは、2026年8月6日までに行った旧実験である。現在の対象施設・人数推定・再配分方法には使わない。
- 旧実験の文書・コード・出力は、検討経緯と再現可能性を残すため保存する。現在の結論や次作業は`CURRENT.md`、`DECISIONS.md`、`NEXT.md`を優先する。

## 更新ルール

- 実装、検証、研究方針に実質的な変化があったときに更新する。
- 完了、未完了、仮説を混同しない。
- MTGの決定事項には、元のMTG記録を付ける。
- コードの完了事項には、確認したテストや出力を記載する。
- `CURRENT.md`は簡潔に保ち、古い経緯は`CHANGELOG.md`へ移す。
- 日付は日本時間で記録する。
