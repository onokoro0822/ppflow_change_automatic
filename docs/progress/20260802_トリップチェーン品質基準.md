# トリップチェーン品質基準

作成日: 2026-08-02 JST

## 結論

元のトリップと復元済みチェーンは変更せず、分析用の品質レイヤーを追加した。

- 出発時刻が0秒以上86,400秒未満のトリップだけを時刻依存分析に使う。
- 負値や86,400秒以上を24時間で剰余化したり、端の時刻へ丸めたりしない。
- 時刻範囲外トリップは元データに残し、分析系列から除外する。
- 前トリップの目的地と次トリップの出発地が200mを超えて離れる場合、レコードを削除せず分析系列を分割する。
- 200mは劉氏らのGPS滞在抽出を参考にした暫定閾値であり、50m、100m、500m等との感度分析対象とする。

このルールは実装上の暫定基準であり、指導教員との確認後に研究上の確定条件とする。

2026年8月6日に研究対象を名鉄百貨店本店の営業終了後再配分へ変更した後も、この品質レイヤーは現行分析の共通前処理として使用する。ミッドランドスクエアを参照施設とする旧実験には依存しない。

## 根拠

Pseudo-PFLOW仕様書ver.2.01は、データを「典型的な平日の24時間」と説明し、
トリップの出発時間を「0時からの秒数」と定義している。このため、負値と86,400秒以上を
通常の1日内時刻として扱う根拠はない。

同仕様書は、擬似データが集計的性質の再現を目的とし、個人レベルでは実移動との乖離が
あり得ることも注意事項として挙げている。そのため、不連続な個人系列を座標補間で修復せず、
系列境界として扱う。

## 全件データへの適用結果

名古屋市16区の7,456,341トリップへ適用した。

- 有効時刻: 7,407,657件（99.35%）
- 範囲外時刻: 48,684件（0.65%）
  - 負値: 563件、最小-45,324秒、最大-18秒
  - 86,400秒以上: 48,121件、最小86,400秒、最大283,860秒
- 範囲外時刻を1件以上持つ人物: 24,416人
- 分析可能なトリップを持つ人物: 2,142,117人
- 分析用系列: 3,038,868系列
- 200m超の空間ギャップによる分割: 896,751回
- 直前が範囲外時刻であることによる分割: 484回
- 分割後も保持された隣接対: 4,368,789組
- 単一トリップだけの分析系列: 1,247,384系列
- 複数の分析系列に分割された人物: 239,301人

全7,456,341件について、`trips`、`chain_links`、`trip_analysis_quality`、
`trip_chain_rows`、`analysis_trip_chain_rows`の件数一致と、SQLiteの
`PRAGMA integrity_check = ok`を確認した。

## 空間閾値の感度

全5,314,167隣接対に対する、各距離以内の割合は次のとおりである。

| 閾値 | 連続とみなされる隣接対 | 割合 |
|---:|---:|---:|
| 0m | 4,073,713 | 76.66% |
| 50m | 4,190,312 | 78.85% |
| 100m | 4,278,233 | 80.51% |
| 200m | 4,412,423 | 83.03% |
| 500m | 4,555,914 | 85.73% |
| 1,000m | 4,622,439 | 86.98% |
| 5,000m | 4,939,842 | 92.96% |

閾値を広げても不連続は相当数残る。したがって、座標誤差を一律補正するより、
分析系列を明示的に分割し、閾値別の結果差を後で検証する方が安全である。

## 実装と生成物

- 品質レイヤー生成: `trip_chain_quality.py`
- 自動テスト: `tests/test_trip_chain_quality.py`
- 品質集計: `output/trip_chains/quality_summary.json`
- 品質テーブル: `trip_analysis_quality`
- 品質適用ビュー: `analysis_trip_chain_rows`

商業目的プロファイルは品質適用ビューを標準入力とし、範囲外時刻を除外し、
200m超のギャップをまたいだ直前・直後活動を接続しない。

## 次の確認事項

- 指導教員とのMTGで、時刻範囲外を除外する方針を確認する。
- 旧本店の正式な抽出境界を確定後、50m・100m・200m・500mの系列分割閾値が、影響対象の前後活動と再配分結果へ与える差を比較する。
- 現行分析は目的100（買い物）を対象とする。自由行動コード400の商業利用判定は、対象範囲を拡張する場合の別課題とする。
