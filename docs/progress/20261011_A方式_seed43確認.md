# A方式 seed43の施設なし／あり比較

確認日: 2026-10-11 JST

## 条件

愛知県2%標本（sample-factor 50）、seed43。seed42と同じ係数・原単位・施設capacityを固定。
シナリオは `config/pflow_capacity/baseline.json` と `config/pflow_capacity/plan_dept2014_f8000000.json`。
計画はメッシュ倍率1、従業者加算745.942954248366人、施設capacity8,000,000。
原単位は暫定で、商業統計と経済センサスの従業者定義差が残る。

実行コマンド（両ケースを順次実行）:

```bash
for scenario in baseline plan_dept2014_f8000000; do
  bash scripts/run_pflow_capacity_sweep.sh --scenario "$scenario" --seed 43 --skip-compile \
    --pflow-args '--shopping-attraction-beta 0.40625 --shopping-mnl-multipliers 0.90625,-0.0625,-4.65625,-0.453125 --shopping-local-mesh-capacity raw' \
    --output-root "$PWD/.local/pflow/output/retail_floor_area_20261009/shared_mesh_fixed/seed43" || exit
done
```

Java・モデル設定の変更はなし。既存のコンパイル結果を使用。

## 確認結果

| seed | 施設買物到着 | 目標360件との差 | メッシュ・施設なし→あり | 中村区・施設なし→あり | 施設出発地TVD（愛知県内） |
| --- | ---: | ---: | --- | --- | ---: |
| 42 | 371 | +3.06% | 542→548 | 985→985 | 0.374972 |
| 43 | 406 | +12.78% | 569→582 | 977→977 | 0.448357 |

seed43の施設来訪者の出発地は、中村区内28.57%、市内他区52.22%、市外愛知19.21%。
seed42では32.61%、50.67%、16.71%。出発地は直前活動地であり居住地ではない。
PT参照は中村区全体の買物で、基本ゾーン510・大型小売施設条件付きではない。
このTVDを新施設の予測精度の検証値とは扱わない。

seed43の施設到着はseed42より35件多い。目標人数への近さと出発地構成にはseed間の変動がある。
区全体の買物到着数が増えない傾向は2つのseedで共通。ただし総数が同じであることから、
個々人の区間移動まで全て変化なしとは結論しない。
2つのseedだけで安定性や信頼区間を確定しない。設定を変えずseed44・45を確認した後にcapacity調整を判断する。
