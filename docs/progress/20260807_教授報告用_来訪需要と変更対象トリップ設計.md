## 0. 教授への報告要旨

2026年8月7日MTGの指示に対し、次のように整理した。

1. 施設の1日来訪者数は全用途共通の係数ではなく、商業は小売店舗面積、ホテルは客室数、
   公園は公園種別、オフィスは延床面積、イベント施設は席数と開催回数から別々に算定する。
2. 最初に実装する計画案は「名古屋駅接続の駅型商業施設」とする。
3. その主要ターゲットは **30〜49歳の男女** とする。Liu氏らの研究で、この年齢・性別群が
   5つの商業施設カテゴリ全てに共通する中核消費者群として抽出されたためである。
4. 初版で変更する中心は、年齢30〜49歳、目的100（買い物）、品質条件を満たすトリップである。
   ただし施設全体は全年齢の目標構成に合わせ、30〜49歳以外も必要数を抽出する。
   飲食は目的200、公園・文化は400、オフィスは2と500とし、用途を混ぜない。
5. 年齢・性別が付いた愛知県全体のPseudo-PFLOWが入手できる前提で、年齢・性別を
   人物マスタへ追加し、施設別の人数制約と属性制約を同時に満たす層化抽出を行う。
6. 旧名鉄百貨店付近の1,977人は、過去の抽出境界とチェーン変更技術を確認した初期実験であり、
   新しい施設の来訪者数や年齢構成の根拠には使用しない。

## 1. 数値の種類と証拠レベル

以後の報告で数値を混同しないため、全てのデータに次の区分を付ける。

| 区分 | 意味 | 例 |
|---|---|---|
| 入力・観測相当値 | Pseudo-PFLOWまたは公的調査に収録された値 | 7,456,341トリップ、公園の年齢構成 |
| 計算値 | 入力から再現可能な式・SQLで計算した値 | 品質適用後の目的別トリップ数 |
| 外部推定値 | 公的原単位や類似施設実績で推定した値 | 商業施設20,000m²の22,000人/日 |
| シナリオ仮定 | 実測根拠ではなく、感度分析のために置く値 | 基準値の暫定±20% |
| モデル出力 | シナリオ実行後に得られる値 | 年齢別流入、交通手段別経路負荷 |

「根拠がある基準値」と「不確実性を見るための仮定」を必ず別列で保存する。

## 2. 現在のPseudo-PFLOWから計算済みのデータ

### 2.1 入力列

現在の1トリップは次の9項目を持つ。

```text
person_id, departure_time_sec,
origin_lon, origin_lat, destination_lon, destination_lat,
transport_mode, trip_purpose, employment_status
```

年齢・性別データ入手後は、トリップごとに重複保存するのではなく、
次の人物マスタを作り `person_id` で結合する。

```text
persons(person_id PRIMARY KEY, age, sex, residence_municipality, ...)
```

これにより、同一人物の全トリップで年齢・性別が一貫する。

### 2.2 トリップチェーンと品質層

名古屋市16区の入力から、同一の `person_id` を出発時刻順に並べ、前後トリップをSQLiteで結合した。

| 指標 | 計算方法 | 現在値 |
|---|---|---:|
| 全トリップ | `trips` の行数 | 7,456,341 |
| 人物数 | `COUNT(DISTINCT person_id)` | 2,142,174 |
| 有効時刻 | `0 <= departure_time_sec < 86,400` | 7,407,657 |
| 範囲外時刻 | 全トリップ − 有効時刻 | 48,684 |
| 空間的に連続する隣接対 | 前トリップ目的地と次トリップ出発地が200m以内 | 4,412,423 |
| 分析用系列 | 範囲外時刻または200m超で分割 | 3,038,868 |

200mは現在の品質処理の暫定閾値であり、施設の誘致圏ではない。

### 2.4 参考実験：旧名鉄百貨店の閉店後再配分

2026年8月6日までに、チェーン変更処理の技術確認として次の参考実験を行った。

```text
対象 = analysis_eligible = 1
       かつ trip_purpose = 100
       かつ旧本店暫定代表点から50m以内
```

この条件で1,986買い物トリップ・1,977人を抽出し、該当トリップを全数変更した。
代替候補は、名古屋市内で30件以上の買い物到着が観測された1,774座標クラスタから作った。
対象トリップ `i` の出発地から候補 `j` への選択重みは次の暫定Huff型である。

```text
w(i,j) = observed_shopping_trips(j)
         / max(straight_distance(i,j), 300m)^1.5

P(i,j) = w(i,j) / sum_j w(i,j)
```

結果は、1,986件が644地点へ移り、目的地1,986件と後続出発地1,773件、合計3,759座標を変更した。
時刻順序違反と変更後チェーン接続ずれは0件だった。旧本店代表点から500m以内に残ったのは
460件（23.2%）、1km以内は588件（29.6%）である。

ただし、1,977人は実測来館者数ではなく50m圏内の一つの座標クラスタに依存する。
距離指数1.5、最低距離300m、観測件数を魅力度とする設定も未校正である。
したがって、この結果は変更コードと検査方法の実証には使うが、新施設の来訪需要や属性の
根拠には使わない。詳細は[閉店後再配分の初版](20260806_名鉄閉店後の買い物目的地再配分初版.md)と
[再配分先の初期確認](20260806_再配分先上位地点初期確認.md)に保存している。

## 3. 施設別の人数計算

### 3.1 商業施設・家電量販店

大店立地法指針から1日来客数を計算する。

```text
日来客数 N_retail = A(S) × S

S: 小売店舗面積（千m²）
名古屋市の商業地区では
  S < 20:  A(S) = 1,500 - 20S（人/千m²）
  S >= 20: A(S) = 1,100（人/千m²）
```

例として小売店舗面積20,000m²なら、

```text
N_retail = 1,100 × 20 = 22,000人/日
```

となる。この20,000m²は研究ケースの仮置きであり、実際の計画として確定した値ではない。
小売店舗面積であり、共用部、ホテル、オフィスを含む総延床面積ではない。

例示用の暫定感度幅を基準値±20%とすると、17,600・22,000・26,400人/日となる。
この±20%は公的原単位ではなく、類似施設3件以上を調査するまでの感度分析仮定である。

家電量販店の総人数にも小売原単位を使えるが、「40代が多い」という属性条件を裏付ける
信頼できる公開資料は現時点で確認できていない。そのため家電量販店の年齢構成は未確定とし、
仮定で40代を増やさない。

根拠:

- [経済産業省 大規模小売店舗立地法](https://www.meti.go.jp/policy/economy/distribution/daikibokouritenporittiho.html)
- [大規模小売店舗立地法指針の式・算定表](https://www.pref.gunma.jp/page/10092.html)
- [国土交通省 大規模開発地区関連交通計画マニュアル](https://www.mlit.go.jp/toshi/city_plan/content/001480895.pdf)

### 3.2 オフィス

```text
人T.E./日 = A × α1 × α2 × 事務所延床面積（ha）
概算の外部来訪人数 ≈ 人T.E./日 ÷ 2
```

都心部・一般事務所ビルの `A=3,800人T.E./ha・日` を使う。
例として1ha、補正係数1なら3,800人T.E./日、単純往復に換算した概数は1,900人/日である。
T.E.は到着と出発の延べ端点数であり、ユニーク人数ではない。

対象人物は就業者、対象年齢は原則20〜64歳、目的は通勤2と業務500を分けて抽出する。
通勤2は就業地の置換、500は従業員以外の業務来訪に使う。

根拠:

- [国土交通省 大規模開発地区関連交通計画マニュアル](https://www.mlit.go.jp/toshi/city_plan/content/001480895.pdf)

### 3.3 ビジネスホテル

```text
宿泊人泊/日 = 客室数 × 客室稼働率 × 1利用客室当たり人数
チェックイン人数/日 = 宿泊人泊/日 ÷ 平均連泊数
```

2025年の愛知県ビジネスホテルの客室稼働率75.4%を基準に使う。
500室の研究例で、1利用客室当たり人数を1.3人と仮置きすると、

```text
500 × 0.754 × 1.3 = 490.1 ≈ 490人泊/日
```

これは平均的な宿泊滞在人数であり、その日の新規来訪者数ではない。チェックイン人数を求めるには、
さらに平均連泊数で割る。1.3人/室と平均連泊数は現時点では未取得であり、宿泊旅行統計の
延べ・実宿泊者数または同種ホテル実績から計算する。飲食、会議、宴会、従業員は別算定する。

観光庁「旅行・観光消費動向調査」2025年確報の国内宿泊旅行の延べ旅行者数から、
出張・業務の宿泊者構成は次のとおりである。

| 年齢 | 構成比 |
|---|---:|
| 0〜19歳 | 2.7% |
| 20代 | 12.4% |
| 30〜49歳 | 35.6% |
| 50〜69歳 | 44.0% |
| 70歳以上 | 5.2% |

元表の10歳階級から30代・40代・50代を合計すると30〜59歳は67.8%、性別は男78.8%・女21.2%だった。
したがって、ビジネス客中心のホテル案の主要対象は **30〜59歳** とし、性別は
公的統計の構成で制約する。一方、観光型ホテルの構成は別であるため混合しない。

根拠:

- [観光庁 宿泊旅行統計調査 2025年年間値](https://www.mlit.go.jp/kankocho/content/002010555.pdf)
- [観光庁 旅行・観光消費動向調査 2025年年間集計表、第11表](https://www.mlit.go.jp/kankocho/content/001998225.xlsx)

## 4. 年齢・性別の設定方法

### 4.1 共通の年齢階級

人物マスタには実年齢を保持し、比較報告ではLiu氏らと接続できる次の5階級を基本にする。

```text
0〜19歳, 20〜29歳, 30〜49歳, 50〜69歳, 70歳以上
```

公園統計のように異なる年齢区分だけが公表されている場合は、原資料の区分と値を保存する。
例えば65歳以上を65〜69歳と70歳以上に分ける必要がある場合は、候補母集団内の実測比で条件付き分割し、
公園調査が公表している65歳以上合計は保存する。

### 4.2 商業案のターゲット

Liu氏らは年齢を5階級、性別を男女に分け、商業施設内の構成比をGPS母集団の構成比で割った
FCPIを用いている。

```text
b(c) = N_base(c) / N_base
p_f(c) = N_f(c) / N_f
FCPI_f(c) = p_f(c) / b(c)
```

`FCPI >= 1.2`、重み付き人数1,000以上、施設カテゴリ内構成比0.5%以上を有意な選好群の条件としている。
主要群は次のとおりである。

- 30〜49歳女性: 全施設カテゴリ
- 30〜49歳男性: 全施設カテゴリ
- 20〜29歳女性: 商業型、オフィス型、住宅型、駅型ショッピングセンター
- 50〜69歳女性: 商業型、住宅型、駅型ショッピングセンター
- 19歳以下女性: 商業型、住宅型、駅型ショッピングセンター

これを踏まえ、初版の実装対象は次とする。

- 主要年齢: **30〜49歳**
- 性別: **男女とも対象**
- 副次層: 20〜29歳女性、50〜69歳女性、19歳以下女性
- 変更目的: **100（買い物）**

重要なのは、施設来訪者の全員を30〜49歳にするのではない点である。
30〜49歳は施設が特にリーチする主要層であり、全年齢の構成比は以下の方法で得る。

1. 年齢・性別付き愛知県Pseudo-PFLOWの品質適用後、目的100の基準構成比 `b(c)` を計算する。
2. 類似する駅型商業施設の年齢・性別FCPIまたは実測構成比を取得する。
3. `p_target(c) = b(c) × FCPI(c) / Σ[b(k) × FCPI(k)]` で目標構成比を作る。
4. 基準来訪数 `N` に対し `n(c) = round(N × p_target(c))` を年齢・性別の目標人数とする。
5. 丸め後の合計が `N` と一致するよう最大余数法で調整する。

Liu氏論文の公開本文では中核群とFCPI閾値は確認できるが、名古屋駅型施設へそのまま移植できる
年齢別の完全な数値表は得られていない。そのため、現時点で任意の年齢構成比を作らず、
**ターゲット層は決めるが、全年齢の割合は年齢付き母集団と類似施設のFCPIを取得してから計算する**。

根拠:

- [Liu et al. (2026), SSRN 6520042](https://ssrn.com/abstract=6520042)
- [保存した日本語要約](/Users/yuuki/Desktop/syuron/関連論文/日本語要約_Liu_et_al_2026.md)

## 5. どのトリップを変更するか

### 5.1 施設用途と変更対象の対応

| 施設用途 | 主対象年齢・属性 | 目的コード | 初版のチェーン変更 | 変更しないトリップ |
|---|---|---:|---|---|
| 駅型商業 | 30〜49歳男女を主要層 | 100 | 既存買い物目的地を新施設へ置換 | 外食200、自由400、通勤2 |
| 飲食フロア | 類似施設調査後に決定 | 200 | 外食目的地を置換 | 買い物100と混ぜない |
| ビジネスホテル | 30〜59歳、出張者構成 | 500が候補 | 宿泊活動と翌日出発を挿入 | 既存業務トリップの目的地単純置換 |
| オフィス | 20〜64歳の就業者 | 2, 500 | 通勤先置換と業務来訪を別系統で生成 | 学生の通勤コード誤付与 |
| 公園・広場 | 公園種別構成に合わせる | 400 | 自由行動目的地を置換、立寄り案は挿入 | 通り抜けは別定義 |
| 文化・イベント | 企画・公演別に設定 | 400 | 開催時刻に合う活動を置換または挿入 | 通常日と公演日を混ぜない |

ホテルは宿泊を直接表す目的コードがなく、現在のデータは24時間分である。
そのため、業務500の目的地をホテルへ置換するだけでは「出張先での業務」と「宿泊」を混同する。
宿泊案は日跨ぎ活動を追加できるデータ設計が必要なため、商業案の後に実装する。

### 5.2 駅型商業案の抽出条件

変更候補トリップ `i` の全集合と、重点層を次で定義する。

```text
E_all = {
  i |
  analysis_eligible_i = 1,
  trip_purpose_i = 100,
  age/sex is not missing,
  person_i has not already been selected for another visit,
  the new route and activity fit before the next departure
}

E_primary = {i in E_all | 30 <= age(person_i) <= 49}
```

`E_all` から全年齢の目標人数を抽出し、その中で30〜49歳男女を重点配分する。
性別は男女とも対象であり、初版では性別を理由に除外しない。
一日来訪者数をユニーク人数として実装する初版では、同一人物から1トリップだけを選ぶ。
大店立地法の「日来客数」と厳密なユニーク人数が同じかは一致しない可能性があるため、
後に同日複数来店の扱いを感度分析する。

到着時刻は現在の列にないため、次のネットワーク所要時間から推定する。

```text
t_arrive_i = t_depart_i + travel_time(origin_i, new_facility, mode_i)

次トリップがある場合:
t_arrive_i + minimum_stay <= t_next_depart_i

次トリップがない場合:
opening_time <= t_arrive_i <= closing_time - minimum_stay
```

これにより、営業時間外のトリップや、直後の活動に間に合わないトリップを除外できる。

### 5.3 人数と構成比を同時に満たす抽出

一つの恣意的な「総合スコア」で計画を評価しない。以下の順で候補者を選ぶ。

1. 外部根拠から施設の総来訪者数 `N` を決める。
2. 年齢・性別、時間帯、距離帯、交通手段の目標構成比を根拠ごとに設定する。
3. 行動目的、営業時間、チェーン余裕時間をハード条件として不適合候補を除く。
4. 残る候補に反復比例法（IPF/raking）またはエントロピーバランシングの重みを与え、
   各周辺分布が目標値に近づくようにする。
5. 重みに比例した非復元抽出を行い、同一人物を1回だけ選ぶ。
6. 抽出後に、総人数、年齢・性別、時間帯、距離帯、交通手段の誤差を出力する。

この方法なら、来訪者数と年齢構成を外部根拠として与え、Pseudo-PFLOWを
その条件を満たす個人別トリップへ変換することができる。

候補数が目標人数より少ない場合は人物を複製しない。市外・観光客母集団の追加、施設規模の見直し、
または不足人数を明示する。

### 5.4 トリップチェーンの変更項目

商業施設の初版では、既存の買い物活動を新施設へ置換する。

| 対象 | Before | After |
|---|---|---|
| 選択した買い物トリップ | 既存の目的地 | 新施設の正式境界内の到着点 |
| 同じ分析系列の直後トリップ | 既存の出発地 | 同じ新施設内の出発点 |
| 目的コード | 100 | 100のまま |
| 交通手段 | 既存値 | 変更後ODとアクセス条件から再推定 |
| 出発時刻 | 既存値 | 原則保持し、新所要時間で成立性を検査 |
| 到着時刻 | 列なし | 経路所要時間から新規推定 |
| 滞在時間 | 直接列なし | 到着時刻から次トリップ出発時刻までとして計算 |

新施設が新しい外出を生む「追加誘発」は、目的地置換と別モデルにする。
初版では既存の買い物回数を保存する目的地置換だけを実装し、次に追加活動の挿入を比較する。

## 10. 主な限界

- 現在の名古屋市16区入力は市外居住者を含まない可能性が高い。名古屋駅の広域集客には愛知県全体が必要である。
- Pseudo-PFLOWは集計的性質を再現する合成データであり、個人の実軌跡ではない。
- 商業原単位は元データと改定時期が古いため、現在の類似施設データで校正する。
- Liu氏の対象は2022年5月の東京23区であり、名古屋の新施設へ直接移植しない。
- 年齢・性別の欠損がある人物を任意に特定年齢へ補完しない。欠損群として別途報告する。
- 目標構成を満たすために人物を複製せず、候補不足はモデルの制約として表示する。
