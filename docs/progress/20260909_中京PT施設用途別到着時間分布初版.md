# 中京PT施設用途別到着時間分布 初版

作成日: 2026-09-09 JST

## 目的

名鉄百貨店跡地を含む到着中ゾーン5について、商業・オフィス・ホテルの来訪者が
何時台に到着するかを中京PTから作り、Pseudo-PFLOWの候補選択へ渡せる初期目標にする。

## 使用データ

/Users/yuuki/Desktop/university/syuron/中京PTデータ/の
chukyo_pt_2022_destination_facility_purpose_time.csvを使用した。
集計条件は発生集中量集計、列項目は「移動終了時」、集計種類は集中量、粒度は中ゾーンである。
実表の先頭列名は「集計種類」だが、値は中ゾーンコードとして並んでおり、中ゾーン5を抽出した。

## 用途条件

出発地分布の目的代理とは異なり、この表には到着施設列がある。そのため次の施設分類と目的を
同時に限定した。

- 商業: 到着施設「大型規模小売店」かつ、買物・飲食・娯楽・観光・その他自由目的
- オフィス: 到着施設「事務所・会社・銀行・郵便局」かつ、出勤・業務・帰社等
- ホテル: 到着施設「宿泊施設・ホテル」かつ、観光・業務・飲食・その他自由目的

用途集合の正確な文字列はchukyo_pt_origin_distribution.pyのFACILITY_USESと共通化した。

## 計算方法

用途f、到着時間帯tについて、時刻不明を除く構成比を次式で求めた。

    P(t | facility=f, purpose∈S_f, D=5)
      = N(t, facility=f, purpose∈S_f, D=5)
        / Σ_t N(t, facility=f, purpose∈S_f, D=5)

全商業型の推定到着人トリップ25,284人は、この商業構成比へ最大剰余法で整数按分した。
25,284人は既存の6シナリオ計算における全商業型の値であり、中京PT原表の25,519件とは別である。

## 解釈上の限界

- これは中ゾーン5の大型規模小売店等をまとめたPT分布であり、名鉄跡地固有の来館実績ではない。
- 1時間帯の到着人数であって、施設内に同時にいる人数ではない。
- 同時滞在人数には、施設用途別の滞在時間または退出時刻が必要である。
- 現行集計表だけでは平日・休日を分離できない。
- Pseudo-PFLOWへ適用するときは、出発時刻そのものではなく、
  出発時刻＋ネットワーク所要時間で推定した到着時刻を目標時間帯へ合わせる必要がある。

## 次の接続

商業候補について、出発中ゾーン、年齢×性別、到着時間帯を同時に満たす選択を行う。
その際、営業時間内の到着、到着後の最低滞在時間、後続トリップ出発時刻との順序を検査する。
滞在時間が得られるまでは、時間帯別到着数までを出力し、同時滞在人数とは表示しない。
