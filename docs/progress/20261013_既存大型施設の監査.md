# 既存大型施設を使う検証の初回監査

確認日: 2026-10-13 JST

## 対象と目的

ユーザーの「区外流入を表すモデルを検討する」依頼に基づき、既存大型施設で規模・立地と来訪分布を結び付けられるか監査した。
参照候補はJR名古屋タカシマヤ本店。【仮】名鉄跡地と同じ名駅の駅直結百貨店を比較対象にする候補であり、施設選定や新モデルの妥当性を確定したわけではない。
[公式会社概要](https://www.jr-takashimaya.co.jp/company/)で、JRセントラルタワーズの大型百貨店、ゲートタワーモール等との区別を確認した。

## 確認したこと

- 名称候補はJavaと同じ`city_retail.csv`の名称・行政界から抽出。元データの電話番号等は転記していない。
- Java `DataAccessor.loadRetailData` は店舗名・施設床面積を選択モデルに渡さず、全小売行をcapacity10,000として扱う。
  テナントや名称重複の行数が施設の取り分に効き、大型施設の床面積を表しているわけではない。
- 名称表記を正規化し、本店候補とゲートタワー・ウオッチメゾン等を区別する設定を作成。
  名前に本店表記がないテナントは所属を確定していない。
- 候補は2座標。主座標には小売42行が重なり、名前一致14行、名前だけでは所属未確定28行。
  もう一方は1行。両方ともメッシュ52366700。
- 保存済み新係数seed42 baselineの207 CSVを集計。2座標への買物到着52件、直前活動が中村区内16件、区外36件（69.23%）、直前活動不明0件。
- これは生成された座標候補の到着であり、観測来店数やタカシマヤ単独の人数ではない。
  建物境界が未確認で、同一座標の店舗を出力から識別できない。
- 出力の到着行政界は中村区35件・西区17件。共有メッシュの行政界選択と物理的な施設所在地がずれる既存仕様がここでも現れる。
  名称を取得した行政界と出力行政界を同一視せず、座標候補全体を保持して内訳を報告した。

## PTと規模情報の不足

確認した5つの既存PT CSVでは、OD表は出発中ゾーン・到着中ゾーン・目的・交通手段で、施設識別子・到着施設条件がない。
到着施設×目的×年齢／時間の表には出発地ODがない。
これらの表を独立と仮定して掛け合わせても、特定施設の実測ODは得られない。
基本ゾーン510の大型小売施設条件付きODが得られても、同ゾーンの施設群とタカシマヤ単独は区別する。

モデルの小売入力に売場面積はなく、本店とテナントをまとめた施設単位の規模は未確定。
公式会社概要の会社全体従業員数を、そのまま店舗・テナントの従業者数として入力しない。
この段階では既存施設除去・再配置による外部検証を完了できない。

## 実装・再現

```bash
.venv/bin/python pflow_existing_facility_audit.py \
  --config config/reference_facilities/jr_nagoya_takashimaya.json
.venv/bin/python -m unittest discover -s tests
```

- 実装: `pflow_existing_facility_audit.py`
- 設定: `config/reference_facilities/jr_nagoya_takashimaya.json`
- 座標処理はJavaの定数シフトを再現。新たな測地系変換の精度を確認したわけではない。
- 同一座標の別店舗混在、行政界の除外、人物ごとの直前活動、不明値の保持、非有限座標をテスト。
- 全97テスト成功。Java・既存係数・capacityは変更せず、新しい長時間生成実験は行っていない。
- ローカル出力: `output/existing_facility_audit/jr_nagoya_takashimaya_seed42.json`
- 保存した集計: [監査JSON](20261013_既存施設座標監査.json)

## 次の最小作業

1. 施設・テナント・座標の対応、売場面積、利用できる観測ODの粒度を揃える。現時点では施設単位検証を「未完了」とする。
2. 現有データで試せる案として、商業メッシュ量と出発地からの距離によるアクセシビリティを上位選択へ渡すPython試作を比較する。
   施設規模の効果を検証したものとは分け、同じ重みを単にlogsumへ書き換えただけでは効果が変わらない点に注意する。
   [Trainのnested logit解説](https://eml.berkeley.edu/books/choice2nd/Ch04_p76-96.pdf)の下位選択肢の魅力集約を参考にする【仮】。
3. 施設単位の魅力に進むには、既存施設の面積・種類・アクセスを同じ定義で整備して推定する。
   新施設だけに恣意的な高倍率を与えて区外流入を作らない。

「区外流入が増えた」モデルや新係数の実装・検証はまだ行っていない。本日の到達点は、既存施設検証の準備と入力・比較条件の不足の特定。
