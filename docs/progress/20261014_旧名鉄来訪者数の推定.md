# 旧名鉄百貨店本店の来訪者数の推定とマニュアル確認

確認日: 2026-10-14 JST。【仮】面積・売上の按分による粗い推定。

## マニュアル確認（大規模開発地区関連交通計画マニュアル 改訂版 平成26年6月）

出典: https://www.mlit.go.jp/toshi/city_plan/content/001480895.pdf

- 地域区分（p.17 別表3）: 「三大都市圏中心部」は昼間人口密度2万人/km²超で、中京都市圏は名古屋市中区のみ。中村区は「三大都市圏郊外部」（3,000人/km²超）で、`nagoya_caluclation`の区分bは正しい。
- 平日の商業原単位（p.16-18）: 11,600×α1（延床5.44haで約0.80）×α2（駅150m以内で1.0）＝9,300人T.E/ha・日（100単位切り捨て）。
- 人T.E（p.9注）: 出発・到着を合わせた数。到着＝÷2は正しい。54,374㎡で50,568人T.E、到着25,284/日。
- 基準値は「平均値＋標準偏差」（p.11-12）。平均で予測すると半数程度の開発で実交通量が上回るため、安全側に設定している。**平均的な来訪者数ではなく設計用の上振れ値。**
- 原単位は延床面積あたり（p.7）。今回入力した54,374㎡は売場面積相当で延床より小さく、この点は過小側。

## 中京PT 2022からの推定

中ゾーン5（名古屋市中村区全域）の大型規模小売店着（平日・圏域住民、`chukyo_pt_2022_od_facility_purpose_age.csv`）:
全目的29,271/日、買物20,796/日（日常的でない買物12,001、日常的な家事・買物8,795）、食事・社交・喫茶3,326、出勤1,168ほか。
店舗別の値はないため、名駅の百貨店間で按分した。

| 店舗 | 売場面積 | 売上（2023年度） |
| --- | ---: | ---: |
| 名鉄百貨店本店（本館＋メンズ館） | 約55,000㎡ | 352億円 |
| ジェイアール名古屋タカシマヤ | 約55,000㎡ | 1,891億円（ゲートタワーモール含む） |
| タカシマヤゲートタワーモール | 約32,000㎡ | （上に含む） |
| 近鉄パッセ | 8,959㎡（営業面積） | 不明 |

- 面積で按分すると百貨店系の約36%、売上で按分すると約16%。来訪1回あたりの購買額は高島屋の方が高いと考えられ、来訪者数の取り分はこの間と見る。
- 中ゾーン5の大型規模小売店にはスーパー・家電量販店なども含まれる（PTの施設区分の定義は未確認）ため、百貨店系の取り分は100%未満。
- 旧名鉄本店の到着（全目的）: 面積按分の上限で約10,600/日、売上按分で約4,600/日（百貨店系＝大型店着の全部と仮定した場合）。
  百貨店系を大型店着の8割とすると約3,700〜8,500/日。**おおむね4,000〜10,000/日**、買物目的はその約7割。
- マニュアル値25,284/日はこの2.5〜6倍。理由の候補: 平均＋標準偏差の設計値、PTは平日・圏域住民のみ（観光客・圏域外を含まない）、按分の粗さ。

## 店舗面積の一覧について

名古屋市内の大規模小売店舗立地法の届出先は名古屋市で、市は届出ごとの公告PDFのみを公開している。店舗面積を含む一覧（CSV等）は見つからなかった。
愛知県の年度別届出一覧（https://www.pref.aichi.jp/soshiki/shogyo/ ）は名古屋市外が対象。
網羅的な面積リストには、全国大型小売店総覧（東洋経済、有料）や名古屋市への照会が必要。
