# 名鉄閉店後再配分の上位目的地点 初期確認

確認日: 2026-08-06 JST

## 結論

再配分した買い物トリップ1,986件は644座標地点へ分散した。最も多いのは名古屋駅周辺で、旧本店代表点から500m以内に460件（23.2%）、1km以内に588件（29.6%）が再配分された。次にまとまった集積は栄駅・栄三越周辺で、500m集約による暫定値は147件（7.4%）だった。金山周辺にも57件（2.9%）の集積がある。

ただし、現在の代替候補は実在施設ではなくPseudo-PFLOWの買い物目的地座標クラスタである。旧本店から200m以内に398件（20.0%）、300m以内に427件（21.5%）が残り、閉店施設の50m円から少し外れた座標へ移っただけの例が多い。近鉄パッセ付近と考えられる座標も上位に含まれるが、近鉄パッセも2026年2月28日に営業終了している。したがって、現段階では「主にどの施設へ移ったか」を確定できず、「主にどの地域・座標へ移ったか」までが確認済みである。

## 現時点で分かった問題

1. 閉店施設を50m円だけで除外したため、同じ建物・隣接街区の別座標が代替候補に残る。
2. 近鉄パッセのように現在営業終了している商業施設も、過去の買い物集積点として候補に残る。
3. 同じ大規模施設や地下街が複数の座標クラスタへ分割され、施設単位の人数になっていない。
4. 駅・地下街・商業施設の境界が近接しているため、座標だけでは施設を一意に決められない。

この結果から、次の処理では旧本店・近鉄パッセ等の営業終了区画をポリゴンで除外し、残る候補座標を現在営業中の施設IDへ対応付ける必要がある。
