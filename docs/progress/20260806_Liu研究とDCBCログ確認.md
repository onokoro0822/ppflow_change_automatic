# Liu研究とDCBCログの確認

確認日: 2026-08-06 JST

## 結論

Luyao Liu（劉璐瑶）氏らの2026年プレプリントは、GPSから既存商業施設の消費者を抽出し、
属性、時間、距離、施設タイプ、買い物前後の活動系列を分析する研究である。
FCPIは施設カテゴリーに対する相対選好を記述する指標であり、施設閉店後の目的地や人流を
直接予測するモデルではない。

DCBCの2026年7月15日・8月5日ログには、その先の研究として、ショッピングセンターの
階層的な選択モデルとシナリオ予測の計画が記録されている。ただし8月5日時点では、
改良済み選択モデルは完成したとの報告がある一方、4施設を使うシミュレーション・検証と
シナリオ予測・応用は着手直後または未完了であり、結果は示されていない。

閉店、営業終了、特定施設の除去を条件とする予測を実施したという記録は確認できなかった。

## 1. 2026年プレプリントで実施済みの内容

- 2022年5月の東京都23区GPSデータを使用する。
- ショッピングセンター4類型と商店街を分析する。
- 建物境界、営業時間、15分滞在を用いて消費者候補を抽出する。
- オフィス勤務者と施設従業員を段階的に除外する。
- GPS母集団に対する相対構成比としてFCPIを計算する。
- 中核消費者群の時間、距離、買い物前後の活動系列を分析する。
- 日常型、仕事組込み型、近隣型、学校結節型の行動パターンを整理する。

この論文は既存施設で観測された行動の記述・分類であり、新設、閉店、需要ショック後の
目的地再配分を推定するものではない。論文中には需要ショックへの脆弱性への言及はあるが、
閉店シナリオの計算結果はない。

## 2. DCBC 2026年7月15日のショッピングセンター選択研究

消費者の選択を二階層でモデル化している。

1. 第1階層: ショッピングセンターか、その他の小売施設か。
2. 第2階層: 具体的にどのショッピングセンターを選ぶか。

比較モデルは、基本MNL、交互作用項付きMNL、MNLベース残差MLP、純粋MLPの4種類である。
第1階層ではMLP、第2階層ではMNLベース残差MLPが最良と報告された。
評価にはlog loss、AUC、Top-1 accuracyを使い、訓練・検証・テストデータを分けている。

説明変数・感度対象として、移動距離、FCPI、近隣候補までの距離、駐車場容量、
最寄りショッピングセンターまでの距離、店舗構成の多様性が挙げられている。
モデル全体は、上位選択と下位選択を持つネステッド型として説明するよう指摘されている。

## 3. DCBC 2026年8月5日時点の進捗

- 改良済みの選択モデルは完成したとの認識が示された。
- 第1・第2階層で、ニューラルモデルが基本MNLより選択精度を改善した結果を整理している。
- 博士論文の最終章として、4つのショッピングセンターを使ったシミュレーションと検証を予定している。
- Pseudo-PFLOW入力用の世帯・個人データを生成し、社会条件を変えたwhat-ifシナリオを行う計画がある。
- 8月5日時点で、シナリオ予測・応用はその週に進める予定で、結果はまだ報告されていない。

したがって、選択モデルは予測へ使える段階に近いが、確認できるログの範囲では、
特定の閉店後シナリオを計算・検証した段階には達していない。

## 4. 同じDCBCログにある別研究との区別

8月5日の前半には、Pseudo-PFLOWの活動系列生成へ施設の増加・減少条件を与える別の発表もある。
ユーザーが円形範囲、施設種別、増加または減少を指定し、介入用Markov連鎖から
baseline/interventionの活動系列CSVを作る構想である。

これは施設変化を扱う点で本研究に近いが、ログでは発表者が切り替わっており、
ショッピングセンター選択モデルとは別の研究として扱う必要がある。また現状は増減の方向だけを
指定し、変化量は利用者が設定できず、特定商業施設の閉店後に既存利用者がどこへ移るかを
推定するものではない。

## 5. 本研究との関係

本研究の対象は旧・名鉄百貨店本店の営業終了後再配分であり、ミッドランドスクエアを別の参照施設として設定する手順は採用しない。

Liu氏の研究から直接利用できるのは、施設境界の定義、消費者抽出、FCPI、距離・施設属性を
使う階層的施設選択、学習・検証方法である。

本研究が明確に追加する部分は次である。

- 施設の営業終了という時点変化を明示的な入力にする。
- 閉店施設を利用していた人物と買い物トリップを全数抽出する。
- 代替先選択後に、到着目的地だけでなく後続トリップ出発地も変更する。
- 個人の時刻順序と空間連続性を検査する。
- Before/Afterのトリップチェーンと人流を出力・可視化する。

ただし、Liu氏のシナリオ章が完成すると目的地選択部分は重なる可能性がある。修士論文の新規性は、
単なる施設選択精度ではなく、古いPseudo-PFLOWへ現在の施設営業状態を統合し、閉店後の
トリップチェーンを整合的に更新する方法として整理するのが安全である。

DCBCログは自動文字起こしで、2026年7月15日は発言者ラベルがほぼ一人に統合され、
2026年8月5日も複数人の発言が`JUE MA`として記録されている。ショッピングセンター選択研究を
Liu氏の継続研究とみなすのは、7月22日の指導MTGでの説明、研究テーマ、FCPI、著者関係の一致に
基づく推定であり、発言者ラベル単独から断定したものではない。
