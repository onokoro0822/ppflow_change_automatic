# 名鉄百貨店閉店シナリオ Before/Afterグラフ 初版

作成日: 2026-08-06 JST

## 結論

暫定代表点50m以内から抽出した1,977人・買い物1,986件を全数再配分した結果について、
Before/Afterを説明する3種類のグラフを作成した。

旧本店代表点から500mを「名古屋駅周辺」の暫定範囲とすると、Afterの買い物先が
500m以内に少なくとも1件残る人は460人（23.3%）、500m以内に残らない人は
1,517人（76.7%）だった。買い物トリップ単位では500m以内460件（23.2%）、
500m超1,526件（76.8%）である。

ただし、1,517人を「名古屋駅を利用しなくなった人」とは呼べない。現在変更しているのは
買い物目的地と直後トリップの出発地であり、鉄道駅の利用、経路、交通手段、通過は
再推定していない。正確には「Afterの買い物先が旧本店代表点から500m超になった人」である。

## 1. 名古屋駅周辺に残る人・外れる人

Afterの買い物先が少なくとも1件、各半径内に入る人を「範囲内」と集計した。

| 代表点からの範囲 | 範囲内に残る人 | 範囲外になる人 |
| --- | ---: | ---: |
| 50m | 0人（0.0%） | 1,977人（100.0%） |
| 200m | 398人（20.1%） | 1,579人（79.9%） |
| 500m | 460人（23.3%） | 1,517人（76.7%） |
| 1km | 588人（29.7%） | 1,389人（70.3%） |

50m以内が0人なのは、再配分候補を作る際に旧本店代表点50m以内を除外しているためであり、
モデルから独立に得られた発見ではない。200m以内には398件が残っており、閉店施設の
すぐ外側や隣接施設へ再配分される問題が見える。

## 2. Afterの買い物先の距離帯

旧本店代表点からAfterの買い物先までの直線距離を、トリップ単位で集計した。

| 距離帯 | 買い物トリップ |
| --- | ---: |
| 0〜50m | 0件（0.0%） |
| 50〜200m | 398件（20.0%） |
| 200〜500m | 62件（3.1%） |
| 500m〜1km | 128件（6.4%） |
| 1〜2km | 288件（14.5%） |
| 2〜5km | 686件（34.5%） |
| 5km以上 | 424件（21.3%） |

最も多いのは2〜5kmの686件である。一方で50〜200mにも398件あり、現在の候補集合には
旧本店や営業終了施設に近すぎる座標が残っている可能性がある。

## 3. 出発地から買い物先までの距離

買い物トリップの出発地から目的地までの直線距離をBefore/Afterで比較した。

| 距離帯 | Before | After | 差 |
| --- | ---: | ---: | ---: |
| 0〜0.5km | 587件 | 468件 | -119件 |
| 0.5〜2km | 506件 | 640件 | +134件 |
| 2〜5km | 540件 | 503件 | -37件 |
| 5〜10km | 334件 | 307件 | -27件 |
| 10〜18km | 19件 | 66件 | +47件 |
| 18km以上 | 0件 | 2件 | +2件 |

平均は2.49kmから2.76kmへ0.27km増加した。短距離の0〜0.5kmが減って0.5〜2kmが増え、
10〜18kmも増えた。ただし交通手段と所要時間は更新していないため、距離増加に対する
移動行動の妥当性検証は未完了である。

## 4. 出力

再現コード:

- `before_after_charts.py`

実行方法:

```text
python3 before_after_charts.py
```

出力フォルダ:

- `output/facility_closure/meitetsu_nagoya_closure_demo/charts/`

主なグラフ:

- `before_after_overview.png`: 3指標を一枚にまとめた進捗報告向け図
- `station_area_people.png`: 各半径で範囲内に残る人・外れる人
- `after_destination_rings.png`: After買い物先の代表点からの距離帯
- `incoming_distance_before_after.png`: 出発地から買い物先までの距離分布

グラフと同じ値を確認できるCSVとして、`station_area_retention.csv`、
`after_destination_distance_bands.csv`、`incoming_distance_distribution.csv`も保存した。

## 5. 解釈上の注意

- 500mは名古屋駅施設全体の正式境界ではなく、旧本店代表点を中心とする暫定円である。
- Beforeの全員が50m以内なのは対象抽出条件による。
- Afterの50m以内が0人なのは候補除外条件による。
- 現在の代替先は座標クラスタであり、施設名と現在の営業状態は未確定である。
- 「駅周辺から買い物先が外れたこと」と「鉄道の名古屋駅を利用しなくなったこと」は異なる。
